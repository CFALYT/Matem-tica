# Matem-tica
Este projeto é para ajudar aos que desejam aprender matemátia desdo o absoluto zero até o nível avançado.
Neste projeto, tenho como alvo àqueles que procuram por materias que os faça sair do absoluto zero e caminhar para o nível avançado, assim como eu precisei um dia e não tive acesso ao que lhes estou disponibilizando.
Tenha em mente que nada aqui é piratiado ou plagiado, pois todo o conteúdo está alocado publicamente na WEB.
